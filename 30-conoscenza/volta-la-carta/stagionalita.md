# L'anno e le lauree

Fonte: [questionario del 25/10/2026](README.md).

| | Mesi |
| --- | --- |
| Pieni | **Febbraio, marzo, ottobre, novembre, dicembre** |
| Vuoti | Gennaio, aprile, maggio, agosto |
| Altro picco | Inizio dell'anno scolastico |
| Migliori per fare cambiamenti | Gennaio, aprile, maggio, giugno, luglio, agosto |
| Chiusure | Natale, agosto, a volte una settimana a giugno |

- Settimana più piena: circa 110 tesi. Mese tranquillo: circa 5.
- Il cliente ordina **3-7 giorni prima della laurea**; ogni tanto il giorno prima.
- **Si chiede sempre il giorno della laurea** e si lavora in ordine di scadenza.
- Le date delle lauree si cercano su internet, solo per alcuni atenei. Un calendario con tutte le date: «forse» utile.
- Nei mesi tranquilli: aggiornamenti alle tesi, nuovi articoli per il negozio, strategie per il web.
