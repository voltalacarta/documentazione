# 90 · Archivio

Documenti superati o chiusi. **Non si cancella nulla: si archivia.**

## Come archiviare

1. Imposta nel frontmatter `stato: archiviato` (e `sostituito-da`, se c'è un documento che lo rimpiazza).
2. Sposta il file qui, mantenendo la sottocartella della sezione d'origine (es. `90-archivio/50-progetti/`).
3. Rimuovilo dall'indice della sezione d'origine e aggiungilo alla tabella qui sotto.
4. Aggiorna i link che puntavano al vecchio percorso.

Le **decisioni** fanno eccezione: restano sempre in `10-decisioni/`, con stato `superato`.
